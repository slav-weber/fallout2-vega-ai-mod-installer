# Fallout 2 Vega AI Mod: installer

## RU

Здесь лежит только установщик мода Fallout 2 Vega AI Mod для Windows: файл `Fallout2-AI-Setup-<версия>.exe` в разделе [Releases](../../releases/latest). Исходного кода в этом репозитории нет.
Для установки нужна своя копия Fallout 2: файлы игры установщик берёт из неё. Во время установки нужен интернет, недостающие файлы мода докачиваются.
Мод в стадии альфы. Сайт мода: https://f2-vega-ai-mod.wloom.dev/
Сообщить о проблеме: Discord мода, https://discord.gg/K7V93b7jd2

## EN

This repository holds only the Windows installer of Fallout 2 Vega AI Mod: `Fallout2-AI-Setup-<version>.exe` under [Releases](../../releases/latest). There is no source code here.
You need your own copy of Fallout 2: the installer takes the game files from it. Installation needs an internet connection to download the remaining mod files.
The mod is in alpha. Mod site: https://f2-vega-ai-mod.wloom.dev/
Report a problem: the mod's Discord, https://discord.gg/K7V93b7jd2
